# EBS pollock early survival pathways


Quarto website for eastern Bering Sea walleye pollock early survival
pathways.

The site synthesizes causal hypotheses affecting survival from eggs and
larvae through age-0, age-1, and age-2 fish reaching age 3. It includes:

- stage-specific evidence synthesis,
- directed acyclic graph alternatives,
- PCMCI+ implementation guidance,
- science-audience infographics,
- public-facing plain-language infographics,
- citation-linked references.

The published site is <https://afsc-assessments.github.io/ebswp_esp/>.

## Repository structure

- `*.qmd` contains the website narrative, causal diagrams, and analysis
  guidance.
- `analysis/` contains scripts that assemble the cohort table and fit
  candidate models.
- `data-raw/` contains source snapshots and future indicator inputs;
  files here retain their source form.
- `data/` contains analysis-ready cohort tables and their data
  dictionary.
- `docs/` is generated by Quarto for GitHub Pages; do not edit it
  directly.

See the README in each data or analysis directory for file-level details
and the intended workflow.

## Reproducible workflow

1.  Add or update source series in `data-raw/`, recording their
    provenance in `data-raw/README.md`.
2.  Run `Rscript analysis/build_cohort_table.R` to align calendar-year
    series by cohort and write `data/cohort_table.csv`.
3.  Review the cohort contract in `data/cohort_table_dictionary.qmd` and
    run the analysis scripts described in `analysis/README.md`.
4.  Render and inspect the complete website.

Render locally with:

``` bash
quarto render
```

The rendered site is written to `docs/` for GitHub Pages.

The repository’s render check uses `quarto render --no-execute` so pull
requests can catch broken citations, YAML, and page structure without
requiring the full local assessment-model environment.
